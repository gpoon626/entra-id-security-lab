# Identity and Access Administration

> Status: Draft

## Overview

This case study documents authorized lab work performed in a Microsoft Entra ID test environment. It focuses on user provisioning, group-based access, role assignment, and the access restrictions created by least-privilege controls.

## Activities Completed

* Provisioned a dedicated test identity.
* Created and reviewed security groups and group membership.
* Verified a Security Reader role assignment through group membership.
* Observed role-based access restrictions when reviewing authentication methods.

## Security Concepts Demonstrated

* Identity and Access Management
* Role-Based Access Control
* Least Privilege
* Group-Based Access Management
* Separation of Duties
